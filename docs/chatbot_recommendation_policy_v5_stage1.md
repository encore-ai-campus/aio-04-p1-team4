# 챗봇 추천 정책 v5 — 1단계

기존 v4 문서는 이전 정책 기록으로 유지합니다. 현재 DB 공통 추천 경로에는 이 문서의 1단계 정책이 적용됩니다. 나머지 대화 정책은 이후 단계에서 변경합니다.

## 변경된 판정

- 활성 대표 메뉴 FK가 연결된 실제 식당 메뉴만 사용합니다. 위치·반경·음식 종류 조건은 유지합니다.
- 가격은 DB의 매장 표시 금액 그대로 사용합니다. 예산 초과 상품은 제외하며 가격 미확인은 포함합니다. price_hint 및 1인분 환산은 사용하지 않습니다.
- 가격이 없으면 `해당 식당의 메뉴 가격 확인 불가`를 표시합니다.
- 오늘 명시적 휴무 및 확인된 영업시간 밖은 제외합니다. 브레이크 타임은 나뉜 영업 구간으로 판단합니다. 익일 종료는 전날 구간도 확인합니다.
- 오늘 시간표가 없거나 불완전하면 `unknown`으로 포함하고 `영업시간 미기재로 인해 알 수 없습니다`를 표시합니다.
- 영업 중이지만 휴무 여부만 NULL이면 `휴무일 확인 필요`를 표시합니다.
- 수집 상태가 missing/failed라도 저장된 메뉴·시간표가 있으면 그 실제 값을 활용합니다. 수집 성공 여부 자체로 탈락시키지 않습니다.
- 품절·인분 여부는 추천 판정 및 경고에서 사용하지 않습니다. 기존 DB 값과 호환용 응답 필드는 유지합니다.
- 영업 확인 식당을 먼저, 이후 영업시간 미확인 식당을 각각 가까운 순으로 정렬하여 최대 3곳 표시합니다. 동일 식당에서는 가격 확인 상품을 우선하여 하나만 선택합니다.
- 확인 필요 식당도 restaurants 배열에 포함됩니다. candidate_restaurants는 응답 호환을 위해 빈 배열로 유지합니다.
- 대표 메뉴 가격 집계는 확인된 상품 가격만 사용합니다. 전부 미확인이면 최솟값·최댓값은 NULL입니다. 일부라도 미확인이면 price_verified는 false입니다.

## 수정 파일

- app/db_recommendations.py: 공통 DB 필터, 누락 경고, 정렬·세 곳 제한
- app/services.py: 누락 가격의 안전한 출력, 채팅 목록과 경고, 품절 필터 제거
- frontend/app.js 및 frontend/bundle.js: 가격 NULL인 홈 후보 표시 오류 방지
- tests/test_recommendations.py: 실제 채팅 응답의 목록·누락 문구 검증
- tests/test_db_first_flow.py: 변경된 정책에 맞는 기존 기대값 수정
- tests/test_recommendation_policy_stage1.py: 정책 회귀 검증

DB 구조·실제 저장 데이터·시드에는 변경이 없습니다. SQLite와 PostgreSQL 공통 SQLAlchemy 조회를 사용합니다. 메뉴 미연결 식당을 임의로 특정 메뉴 식당으로 추천하지 않습니다.

## 직접 검증

1. C:\temp_resolved에서 기존 run.ps1 방식으로 서버를 재시작합니다. 실제 DB에 해당 메뉴 FK가 연결되어 있어야 합니다.
2. 위치·반경·음식 종류·예산을 정하고 채팅에서 `짜장면 식당 알려줘`처럼 요청합니다. 최대 3곳의 식당명·실제 상품명·표시 가격을 확인합니다.
3. 해당 데이터 중 가격 미확인 식당이 있으면 가격 대신 정확한 확인 문구가 출력되는지 확인합니다. 영업시간 미확인은 해당 문구가 출력되어야 합니다.
4. 알려진 가격보다 예산을 낮춰 조회하면 그 상품이 제외되어야 합니다. 단, 같은 식당에 다른 예산 이내 상품이 있으면 그 상품으로 표시될 수 있습니다.
5. 현재 시간 기준 영업 중 식당이 미확인 식당보다 먼저 나오고 각 그룹 안에서는 가까운 순인지 확인합니다. 영업 중 식당이 3곳 이상이면 미확인 식당은 표시되지 않을 수 있습니다.
6. 실제 DB에 누락·휴무·브레이크 타임 사례가 없으면 아래 자동 검증으로 안전하게 확인합니다. 운영 데이터를 일부러 바꿀 필요는 없습니다.

PowerShell 자동 검증 명령:

```powershell
cd C:\temp_resolved
.\.venv\Scripts\python.exe -m pytest tests/test_db_first_flow.py tests/test_recommendation_policy_stage1.py tests/test_recommendations.py -q -p no:cacheprovider
```

테스트는 임시 SQLite를 사용하며 실제 DB·카카오·Groq를 변경하거나 호출하지 않습니다. 오늘을 고정한 테스트로 가격/시간 누락, 휴무, 브레이크 타임, 예산, 품절 무시, 정렬을 검증합니다.
