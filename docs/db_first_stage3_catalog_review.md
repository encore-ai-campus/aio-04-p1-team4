## 연결 규칙

식사 메뉴 목록을 명시적으로 확장하고 정확한 대표 메뉴명·확인된 별칭으로 비교했다. 원본 상품명·실제 가격·출처 URL·확인 시각은 변경하지 않았다. 대표 메뉴에는 기준가격을 넣지 않았다. 부분 문자열이나 유사도만으로 서로 다른 음식을 묶지 않았다.

추가 예시: 제육볶음, 육개장, 부대찌개, 순두부찌개, 순대국, 갈비탕, 물냉면, 비빔냉면, 김치볶음밥, 간짜장, 새우볶음밥, 알밥, 회덮밥, 치즈돈가스, 참치김밥 등.

별칭 예시: 순댓국·순대국밥→순대국, 만둣국→만두국, 치즈돈까스→치즈돈가스, 간자장→간짜장. 재료가 다른 메뉴는 구분하고 까르보나라도 일반 크림 파스타와 별도 대표 메뉴로 두었다.

명시적인 1인분·보통 표기만 제한적으로 비교용 이름에서 정리했다. 원본 상품명은 그대로 남긴다. 대·중·모듬·세트·커플·무게 상품은 임의로 단일 식사로 바꾸지 않는다. 치즈 피자는 인분 확인 전 추첨 연결을 보류했다.

대표 메뉴 ID는 정규화한 이름의 해시로 생성해 재실행 시 동일하다. 기존 대표 메뉴 ID는 보존한다. 실제 상품이 연결되지 않는 대표 메뉴 제안은 최종 예정 카탈로그에서 제외했다.

## 남은 판단과 권고

연결된 2,969건 중 명시적인 1인 표기는 37건이고 나머지 2,932건의 인분은 미확인이다. 떡볶이·탕류 등은 이름만으로 1인 가격인지 보장할 수 없다. 자동 연결은 음식 종류 대응이며 판매 가능·1인분·현재 영업이 확인됐다는 의미가 아니다.

대표 메뉴 미연결 32,262건 중 27,209건은 추가 검토 상태이고 5,053건은 추첨 제외 제안 상태다. 미연결 상품 전체를 자동으로 새 대표 메뉴로 만들지 않았다. 두부김치·먹태처럼 식사인지 안주인지 맥락이 필요한 사례도 보류했다.

실제 적재 때는 검토되지 않은 상품도 원본 보존용으로 저장할 수 있지만 대표 메뉴 FK는 비워 두어야 한다. 승인 범위는 식당·전체 상품 보존 여부, 대표 메뉴 152종 연결안 채택 여부, 인분 미확인 상품의 추첨 정책을 구분해 정해야 한다. 영업시간 추가 수집과 DB 중심 추천 전환은 별도 후속 단계다.

## 결과 파일

폴더: tmp/csv_stage3_catalog_review/

- menu_catalog.csv: 대표 메뉴 152종과 연결 상품 수.

- reviews.csv, excluded_rows.csv: 기존 분류 검토·가격 충돌·메뉴명 누락 자료.

검토 전용 열이 포함되어 있으므로 CSV를 Supabase에 그대로 업로드하는 방식은 사용하지 않는다. 승인 후 전용 적재 도구에서 컬럼 허용 목록·타입·NULL을 검증해야 한다.

## 검증

전체 상품 분류 합계 일치, 대표 메뉴 FK 대상 존재, 별칭 정규화명 중복 없음, 추첨 제외 상품의 FK 공란, 기준가격 공란, 식당·상품 수 보존을 확인했다. 짬뽕밥의 분류를 중식으로 정리했다. 11인·21인 등의 숫자에 포함된 1을 1인으로 오인하지 않도록 했다.
