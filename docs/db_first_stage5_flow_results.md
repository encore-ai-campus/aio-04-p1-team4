# DB 중심 추천 흐름 전환 결과

> 후속 최종 점검에서 구형 테스트 정리와 README 갱신을 완료했다. 최신 결과는 [6단계 최종 점검 기록](db_first_stage6_final_verification.md)을 참고한다. 아래는 5단계 완료 당시의 기록이다.

작업 경로: `C:\temp_resolved`. `C:\TeamProject_1`과 `C:\temp`는 수정하지 않았다.

## 적용한 흐름

1. 홈 조건 입력: 선택 위치·반경·예산·업종에 맞는 DB 메뉴와 표시 가격 범위, 식당 수를 조회한다.
2. 게임: 같은 DB 후보를 추첨한다. 기존 게임 화면과 애니메이션은 유지했다.
3. AI: Groq는 질문 의도와 조건 변경안을 해석한다. 메뉴·가격·식당 답변은 DB 조회 결과로 생성한다.
4. 지도: 같은 DB 조건으로 검증한 식당을 카카오 지도에 표시한다. 식당 검색 API나 상세 수집을 요청 중 실행하지 않는다.

공통 판정은 `app/db_recommendations.py`에 모았다. 대표 메뉴 FK가 연결된 활성 상품 중 확인 가격이 예산 이내이고, 반경·업종·저장된 영업시간 조건을 통과한 식당만 추천한다. 품절 또는 폐업이 확인된 데이터는 제외한다. 영업정보나 메뉴 정보 수집이 성공하지 않은 식당은 추천에서 제외한다. 이름 부분 일치나 seed의 기준가격으로 후보를 보충하지 않는다.

인분 미확인 상품은 표시 가격 기준 후보로 허용하며 홈·게임 결과·AI·지도 목록과 상세에 미확인 안내를 표시한다. 판매 상태 미확인과 이동시간 미검증도 구분한다. 저장된 영업시간으로 현재 영업 여부를 판단하므로 실시간 매장 상황을 보장하지 않는다.

브라우저 Geolocation, 주소·장소 입력 검색, 카카오 지도 SDK와 길찾기 기능은 유지했다. DB 전용은 추천 메뉴·식당 데이터의 조회 경로에 해당한다.

PostgreSQL 요청 세션에는 `SET TRANSACTION READ ONLY`를 적용했다. 조회 대상은 기존 `Lunchrun` 스키마이며 public에는 테이블 생성이나 적재를 수행하지 않았다.

## 검증

- Python 14개 통과: 공통 후보 조건, 예산·거리·업종·폐업·영업정보·품절 제외, 대표 메뉴 연결, 인분 미확인 표시, 외부 검색·DB 쓰기 없는 추천, 영업시간 판정, 실제 Chromium 홈→게임→지도와 역순 뒤로가기, AI 메뉴 추천·식당 조회, Enter 전송/Shift+Enter 줄바꿈.
- Node 8개 통과: 요청 계약, 조건 변경 시 결과 무효화, 공유 상태와 오래된 응답 차단.
- 변경한 JavaScript 문법 검사와 프론트 번들 재생성 완료.
- 실제 Supabase 읽기 전용 조회에서 한 기준점의 후보 40종과 선택 메뉴 식당 4곳을 확인했다. 이 수치는 조회 위치·시간에 따라 달라진다.
- 데이터 수량 유지: 식당 2,174곳, 상품 35,231건, 대표 메뉴 152종, 영업시간 11,083행. 대표 메뉴 연결 상품 2,969건 유지.
- 상품 전체 SHA-256이 이전 수집 기준과 일치했다: `86d157b17d819d8fd64e0ca9679d431b75fedf075db7f65fcabd321a30f25205`.

## 남은 테스트 정리 사항

전체 테스트가 통과한 것은 아니다. 기존 `chat-session-ui.test.cjs`, `restaurant-ui.test.cjs`는 ES 모듈 소스를 일반 VM 스크립트로 실행하는 구조에서 실패했고, `map.test.cjs`는 현재 없는 `frontend/map.js`를 참조한다. 이번 단계에서는 이 구형 테스트를 새 화면 구조로 재작성하지 않았다. 현재 흐름은 별도 실제 브라우저 통합 테스트로 검증했다. 기존 외부 식당 검색·카탈로그 가격 대체를 전제로 작성된 테스트도 새 DB 전용 계약에 맞춰 별도 정리가 필요하다.

검증 중 Groq 의도 응답과 카카오 지도 SDK는 테스트 대역을 사용했다. 실제 유료·무료 API 호출이나 지도 키·등록 도메인의 유효성을 이번 검증으로 보장하지 않는다.

커밋과 push는 수행하지 않았다. README와 기존 사용자 변경은 이번 단계에서 편집하지 않았다.
