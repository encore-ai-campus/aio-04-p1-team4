# 음식 조건 정리 v2

- 작성일: 2026-11-11
- 이 문서는 기존 문서의 채식·맵기 입력 설명을 대체한다. 이전 버전 문서와 프롬프트는 이력 보관용으로 유지한다.

## 변경 내용

- 홈·조건 수정 창의 채식 선택과 매운 음식 허용 체크박스를 제거했다.
- 조건 요약, 기본값, 폼 저장, API 전송과 채팅 조건 변경에서 `diet`, `spicy`를 제거했다.
- `Conditions`와 `ConditionPatch`는 시간·예산·음식 종류를 관리한다. 검색 반경은 기존처럼 별도로 관리한다.
- Groq에 맵기·채식 필터를 요청하면 지원하지 않는 조건이라고 안내한다.
- 식당 카드와 지도에서 매번 노출하던 채식·맵기 미확인 문구를 정리했다.
- 메뉴 추첨에는 기존처럼 음식 종류·예산과 주변 DB 메뉴 근거를 적용한다.

## 현재 적용 파일

- `app/prompts/system_v3.txt`
- `app/prompts/examples_v3.json`
- `app/prompts/replies_v4.json`

이전 프롬프트 파일은 삭제하지 않고 보관하며 코드는 위 최신 파일만 참조한다. DB에는 두 조건 열이 없으므로 DB 마이그레이션은 필요하지 않다.

## 직접 확인

1. 실행 중인 서버를 종료하고 `run.ps1`로 다시 시작한다.
2. 브라우저에서 `Ctrl+F5`로 새로고침한다.
3. 홈과 조건 수정 창에 점심시간·예산·음식 종류만 남았는지 확인한다.
4. 조건 요약에 채식·맵기가 나타나지 않는지 확인한다.
5. 랜덤 메뉴 추첨과 채팅 요청의 `conditions`가 `minutes`, `budget`, `cuisine`만 포함하는지 Network 탭에서 확인한다.
6. 채팅에 `완전 채식으로 바꿔줘`를 입력하면 적용 버튼 대신 미지원 안내가 나오는지 확인한다.

서버 재시작으로 이전 메모리 세션은 초기화된다. 이전 브라우저 요청 형식은 삭제된 필드로 인해 422가 발생할 수 있으므로 화면도 함께 새로고침해야 한다.
