## 실행 오류 원인

게임 서버 games/server.mjs는 HOST·PORT를 실행 주소로 사용한다. HOST가 외부 DB 주소이고 PORT가 5432이면 해당 PC에 없는 주소에서 listen하려다 EADDRNOTAVAIL이 발생한다. 현재 터미널에서 HOST=127.0.0.1, PORT=4174로 지정하고 node games/server.mjs를 실행한다. DB 연결 문자열은 별도로 유지한다. 테스트 서버는 실행 주소와 포트를 명시하여 검증했다. 사용자의 별도 터미널 환경변수는 변경하지 않았다.

## 검증 범위와 제한

브라우저 테스트는 격리된 SQLite 테스트 DB를 사용했다. 실제 Supabase는 별도로 읽기 전용 연결과 테이블 건수 조회를 확인했으며, 전체 실제 데이터로 모든 UI 조합을 실행한 것은 아니다. 브라우저의 카카오 SDK·외부 경로와 Groq 응답은 대체 응답을 사용하므로 외부 서비스의 실시간 응답과 지도 타일은 사용자의 실행 환경에서 별도로 확인해야 한다.

Starlette TestClient의 httpx 사용에 관한 폐기 예정 경고 1건이 있었으며 테스트 실패는 없었다. 커밋·push는 하지 않았다.
