# 프론트 병합 5단계: 지도 통합 화면

작업 위치: C:\temp_resolved. C:\temp와 C:\TeamProject_1은 수정하지 않았다.

## 변경

- /map/에 홈·게임과 동일한 로고, 위치 변경, 게스트 프로필 헤더를 적용했다.
- 흰색 카드, 주황색 버튼, 둥근 입력창·대화상자와 모바일 배치를 적용했다.
- 우측 하단 화면 이동 메뉴를 추가했다. 경로 탐색은 선택한 식당의 길찾기 영역으로 이동하며 /map/ 안에서 동작한다.
- 기존 integration.js의 식당 조회·조건·위치·랜덤 선택·메뉴 검색·상세·길찾기 로직은 변경하지 않았다. 클러스터 숫자 전용 표시도 유지했다.
- 이전 전체 화면 높이 제한을 덮어써 상세·목록을 자연스럽게 스크롤할 수 있도록 했다.

## 변경 파일

- kakao-map/index.html: 공통 헤더, 이동 메뉴, 디자인 파일 연결
- kakao-map/map-integration.css: 기존 지도에 적용하는 디자인 계층
- kakao-map/map-shell.js: 헤더 및 화면 이동 메뉴 연결
- tests/test_map_design.py: 데스크톱·모바일 UI와 실제 테스트 DB 연결 검증

## 검증

Python 테스트 10개 통과: 지도 라우터·상세·DB 중심 홈→게임→지도 역순 이동·기존 게임/지도/길찾기 브라우저·새 지도 디자인. 지도 JavaScript 테스트 3개 통과. 디자인 테스트는 최종 CSS 변경 뒤 재실행하여 통과했다.

화면 캡처: output/frontend_merge_stage5의 map/menu/detail 데스크톱·모바일 PNG.

브라우저 검증에는 격리된 테스트 DB와 카카오 SDK 대체 응답을 사용했다. 지도 타일과 실제 외부 도보 경로 서비스의 실시간 가용성은 이 검증으로 보장하지 않는다. 실제 Supabase 데이터는 변경하지 않았다. 커밋·push는 수행하지 않았다.
