# 실제 외부 서비스 연결 확인

C:\temp_resolved의 기존 앱을 127.0.0.1:8000에서 실행하고 대체 응답 없이 확인했다. 앱 디자인·백엔드 코드·환경변수 파일·DB 데이터는 수정하지 않았다. 점검용 서버는 종료하며 사용자의 기존 서버와 별개다.

## 카카오 지도

- 실제 dapi.kakao.com SDK와 kakaocdn 스크립트 HTTP 200.
- 실제 지도 타일 HTTP 200, 지도 내 이미지 21개 로드 완료.
- 카카오 Map 객체 생성 및 오류 안내 숨김 확인.
- 가산디지털단지 지도, 출발 마커와 반경 원을 화면 캡처로 확인했다.
- 캡처: ../output/live_connections/kakao-map.png
- 이번 검사는 지도 연결 검사이며 실제 외부 도보 길찾기는 호출하지 않았다.

## Groq 챗봇

- 모델 목록 조회로 API 인증 및 설정 모델 사용 가능 상태 확인.
- /ai에서 첫 질문을 전송하고 실제 채팅 답변을 수신했다. 조건 요약 요청에 대상과 내용을 구체화해 달라는 확인 질문으로 응답했다.
- 추가 메뉴 추천 질문은 groq_rate_limit(외부 HTTP 429)으로 실패했다. 따라서 현재 한도에서 실제 메뉴 추천 완료까지는 검증하지 못했다. 키 인증 오류나 로컬 서버 연결 실패와 구분된다.
- 추가 재시도로 사용량을 늘리지 않았다. 한도가 회복된 후 실제 추천 완료를 재확인할 수 있다.
- 캡처 및 최종 응답 요약: ../output/live_connections/

점검 스크립트는 사용자 기본 경로 C:\AI4\lunchrun_live_check.py에 보관했다. 키와 인증 헤더는 보고서에 기록하지 않았다. 커밋·push는 하지 않았다.
