## 외부 호출 없는 검사

- 허용되지 않은 필드·메뉴 ID·타입·반경 거부
- 의도와 조건 변경안 불일치 거부
- 중복 JSON 키·NaN 거부
- 확인 질문에 가짜 매장 가격이 있어도 고정 안내로 대체
- 조건에 맞지 않는 지정 메뉴는 카카오 검색하지 않음
- 조건 변경안·범위 밖 의도·추가 확인은 카카오 검색하지 않음
- 실제 검색과 빈 결과·외부 오류 처리 유지
- 추천 응답의 메뉴·조건·후보 수·미확인 정보 구분

실제 매장 조건을 검증했다고 안내하면 안 됩니다.
