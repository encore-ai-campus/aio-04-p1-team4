# LUNCH RUN · frontend_UI_03

`frontend_UI_02`를 보존하고 사용자 수정 요청을 반영한 별도 실행 버전입니다.

```powershell
cd C:\01_project\frontend_UI_03
python frontend_main.py --port 8089
```

브라우저: http://127.0.0.1:8089 . `index.html` 직접 열기도 예시 모드로 지원합니다. Python 3.10 이상, 추가 패키지 불필요.

## 변경 사항

- 상단 위치·계정 아이콘만 38px SVG로 확대. 문구 크기는 20px 유지.
- 하단의 ‘예시 데이터 · 실제 서비스 연동 없음’ 표시 삭제. 실제 DB/API가 연결된 것을 의미하지 않습니다.
- conditions, budget, time, distance, people에서 플로팅 내비게이션 숨김. 호환 경로 end-time에서도 숨김.
- 예산 기본 5,000원. 직접 숫자 입력·실시간 천 단위 콤마. 최소 1,000원, 최대 100,000,000원. ± 버튼은 1,000원 단위로 조정하고 범위를 넘지 않습니다. 비우거나 최소 미만 값을 입력하면 포커스를 벗어나거나 적용할 때 1,000원으로 보정합니다. 슬라이더 없음.
- 점심 종료 시간: AM/PM 선택·시 1~12·분 0~59 직접 입력. ± 버튼은 10분 단위이며 정오/자정 경계에서 AM/PM을 전환합니다. 시/분 오류 시 적용하지 않고 안내합니다. 슬라이더 없음.
- 조건 화면에도 종료 시간(예: PM 12:30)을 표시합니다. 추천 요청의 `remaining_minutes`는 오늘 Asia/Seoul 현재 시각과 종료 시각의 차이로 계산하며 이미 지난 시각은 0입니다. 다음 날로 자동 이월하지 않습니다. `lunch_end_time`은 24시간 HH:mm 문자열로 함께 전송합니다. 날짜 선택·왕복·식사·대기 포함 여부는 별도 합의 필요.
- 거리·인원 슬라이더 핸들 58px로 확대. 각 설정의 돌아가기 버튼은 ‘적용’으로 변경.

## 수정 구조

- `index.html`: 헤더·공통 구조
- `styles.css`: 시안 스타일, 화면별 메뉴 숨김, 인풋·슬라이더
- `app.js`: 조건·화면 이동·검증·데모 동작
- `api.js`: API 어댑터, 예시 데이터
- `assets/`: 원본 SVG 로고, 게임/지도 삽화, 비교용 시안
- `frontend_main.py`: 개발용 로컬 서버 및 config.json

JS 수정 후 `node build.cjs` 실행 → 새로고침합니다. Node는 재빌드에만 필요합니다. `upgrade.cjs`는 적용 완료한 일회성 변환 기록이므로 재실행하지 마세요.

백엔드 연결은 `--api-base http://127.0.0.1:8000`으로 지정합니다. 다른 포트의 백엔드는 UI origin에 CORS 허용이 필요합니다. DB에 직접 연결하지 않으며 비밀키를 프론트에 넣지 않습니다. 계약 초안은 `api_contract.md` 참고.

조건 화면의 `게임으로 메뉴 고르기` 버튼은 예산·남은 시간·거리·인원·음식 카테고리와 설정한 현재 위치를 같은 탭의 세션 저장소로 게임 화면에 전달합니다. 게임의 메뉴 후보와 모임방은 전달받은 조건을 사용하며, 위치 좌표는 주소에 노출하지 않습니다. `/games/`를 제공하는 FastAPI와 Node.js 서버를 모두 실행해야 합니다. 게임 서버 실행 방법은 `games/README.md`를 참고하세요. AI 추천·식당·지도 예시는 기존대로 유지됩니다. 홈 화면의 마우스 호버용 화면 검토 메뉴는 제거했습니다. 전체 시안 갤러리는 과거 비교용 원본 PNG이므로 이번 입력 변경과 다를 수 있습니다.

## 검증

백그라운드 브라우저에서 5개 지정 경로의 메뉴 숨김·게임 화면 메뉴 유지·예산 1,000,000 입력/증가·1억원 상한·1,000원 하한·PM 11:55→AM 12:05→PM 11:55를 확인했습니다. Python/JavaScript 문법 검사를 수행했습니다. 이전 UI 02 폴더는 수정하지 않았습니다.
