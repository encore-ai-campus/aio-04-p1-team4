LUNCH RUN 화면 구현 파일

1. 화면 파일 위치
   examples/kakao-map/index.html : 지도, 가게 목록, 가게 정보창
   examples/kakao-map/styles.css : 공통 디자인
   examples/kakao-map/app.js : 지도, 검색, 룰렛, 가게 정보, 길찾기 화면 동작
   examples/kakao-map/menu-catalog.html : 금천구 전체 메뉴 검색 화면
   examples/kakao-map/menu-catalog.css / menu-catalog.js : 메뉴 화면 디자인과 동작
   나머지 JavaScript 파일 : 메뉴·식당·분류·영업시간 데이터 및 기능 모듈

2. 실행하기
   이 폴더의 .env.example을 .env라는 이름으로 복사하고 기존 카카오 키를 입력합니다.
   기존 프로젝트의 .env 설정을 재사용하려면 이 폴더 루트에 .env를 두면 됩니다.
   실제 키가 있는 .env 파일은 이번 복사본에 포함하지 않았습니다.

   KAKAO_JAVASCRIPT_KEY : 실제 지도 표시와 장소 검색
   KAKAO_REST_API_KEY : 서버에서 도보 길찾기 조회

   start_site.cmd를 더블 클릭하고 http://localhost:5500/ 을 엽니다.
   Python 3가 필요하며 별도의 Python 패키지 설치는 필요하지 않습니다.
   명령으로 실행할 때는 이 폴더에서 다음과 같이 실행합니다.
   python examples/kakao-map/serve.py

   기존 사이트 서버가 5500번 포트에서 실행 중이면 먼저 해당 서버를 종료한 뒤
   복사본의 서버를 실행하세요. 이번 파일 복사는 기존 서버를 변경하지 않았습니다.
   카카오 JavaScript SDK 허용 도메인은 http://localhost:5500 을 사용합니다.
   메뉴 검색 화면: http://localhost:5500/menu-catalog.html

3. 개발 시 참고
   HTML 파일을 직접 더블 클릭하면 지도·서버 길찾기 연결에 제약이 있으므로
   위 개발 서버를 사용하세요. 일반 정적 서버만으로는 도보 경로 API가 동작하지 않습니다.
   serve.py와 walk_routes.py는 화면을 실행하기 위한 작은 서버 파일입니다.
   데이터는 현재 사이트의 스냅샷이며, 데이터 수집·가공 스크립트와 조사 기록은 포함하지 않았습니다.
   파일의 상대 경로를 유지하면 복사본을 별도로 수정할 수 있습니다.
   복사목록.json에서 복사한 원본 파일 목록과 해시를 확인할 수 있습니다.
